# Internationalization (i18n)

## Supported languages

| Code | Language | Status |
|------|----------|--------|
| `en` | English | Default |
| `fr` | Français | Complete |
| `es` | Español | Complete |
| `de` | Deutsch | Complete |
| `ja` | 日本語 | Complete |
| `pt` | Português | Complete |

## Quadrant labels

Quadrant action labels use the standard terms from productivity literature in each language:

| Quadrant | EN | FR | ES | DE | JA | PT |
|----------|----|----|----|----|----|----|
| Urgent + Important | DO | FAIRE | HACER | ERLEDIGEN | すぐやる | FAZER |
| Not Urgent + Important | SCHEDULE | PLANIFIER | PROGRAMAR | TERMINIEREN | 計画する | AGENDAR |
| Urgent + Not Important | DELEGATE | DÉLÉGUER | DELEGAR | DELEGIEREN | 人に任せる | DELEGAR |
| Not Urgent + Not Important | ELIMINATE | ÉLIMINER | ELIMINAR | ELIMINIEREN | やらない | ELIMINAR |

Sources: Asana, Wikipedia (Eisenhower-Prinzip), Karrierebibel, Indeed Japan, TOTVS.

## How it works

- Language is stored as synced widget state (`lang`), shared across all collaborators
- Figma does not expose the user's UI language, so the language is selected via a dropdown in the property menu
- The `t(lang, key)` function provides type-safe lookups with fallback to English
- `TranslationKey` is derived from the English translation object keys
